Three steps to let a personal AI trade with a merchant.

Settled is the merchant-side negotiation and assurance desk. The merchant publishes policy and protection; a consumer's AI presents a mandate; both agents negotiate; PayPal settles; the buyer gets recourse. No custody, no new checkout, no card data.

Step 1 · Merchant

Connect PayPal + set policy

Install the Settled app from the PayPal partner directory (or run the server beside your store) and set three things: trust credential, protection tier, and the seller's private policy.

PAYPAL_LIVE=1 PAYPAL_CLIENT_ID=... PAYPAL_CLIENT_SECRET=... PAYPAL_ENV=sandbox # seller policy is server-side: # floor hidden, auto_accept, tiers
Step 2 · Checkout

Bind the contract, then order

At checkout, create a policy-bound contract and place the order at the agreed price. The ACC hash travels on the PayPal order.

POST /api/contracts { "merchant_id":"m1", "product_id":"p1", "buyer_agent_id":"a1" } POST /api/merchants/m1/orders { "contract_id":"ctr_...", "agent_id":"a1" }
Step 3 · Consumer AI

Present a passport + mandate

The personal AI verifies itself, negotiates within the mandate, and signs. Any AI can call the API; MCP tools are the packaging step.

POST /api/agents/verify { "agent_id":"a1", "merchant_id":"m1", "amount":249 } POST /api/contracts/:id/ai-auto # -> signed contract + dialogue
Judge path: the hosted demo runs in SIM (no keys, no money). Click /demo.html → Reset → Run full demo. Step 3 shows the merchant agent and the consumer's personal agent negotiating in the open; step 5 shows the instant refund.
